# Photos for 179 Elams Ranch Rd

The photos are in. This folder holds what the page shows.

## What's here

- **8 camera photos** (`20260831_*.jpg`) — unaltered, shown in the main gallery.
- **5 altered images** (`collov-ai_*.jpg`) — shown below the gallery in their own
  block, each labelled either **Digitally enhanced** (evening sky and lighting added)
  or **Virtually staged** (furniture placed digitally in an empty room).

All were resized to 2000px on the long edge and re-saved at quality 82 for the web —
30.7 MB down to 6.9 MB, with no cropping or retouching. The full-resolution originals
are untouched in Dropbox at `_LEGACY/_Listings/179 Elams Ranch Rd listing/corrected/`.

## Adding or swapping photos

Order and captions are set in `../index.html`, in the `SHOTS` and `STAGED` arrays near
the bottom of the file. Each entry is a filename, a caption, and — for altered images —
a `tag` that draws the badge on the tile and in the lightbox viewer.

To add a photo: upload the file here (GitHub → **Add file → Upload files**), then add a
line to the right array. A filename listed in the array but missing from this folder just
drops out of the grid, so a half-finished upload never breaks the page. Uploading in
batches of about five avoids the 400 error GitHub's uploader gives on large batches.

## The disclosure matters

The altered images carry a visible label because MLS and advertising rules require
materially altered listing photos to be disclosed. If one moves into the unaltered
`SHOTS` array it loses that label — so keep enhanced and staged images in `STAGED`.
